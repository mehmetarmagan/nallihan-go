# NallıhanGo

NallıhanGo, Nallıhan'daki öğrenciler ve yerel kullanıcılar için tasarladığım yemek ve market sipariş arayüzü projesi.

Projede kullanıcıların yemek seçeneklerini inceleyebileceği, menü detaylarını görüntüleyebileceği ve sepet üzerinden ürünlerini takip edebileceği bir yapı oluşturmaya çalışıyorum.

## Özellikler

- Ana sayfa ve hizmet kategorileri
- Yemek ve market sayfaları
- Menü ve ürün detayları
- Sepet arayüzü
- Mobil cihazlara uygun sayfa tasarımı
- JavaScript ile temel etkileşimler

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Dosya Yapısı


## Çalıştırma

Projeyi bilgisayarına indirdikten sonra `index.html` dosyasını tarayıcıda açarak arayüzü inceleyebilirsin.

Geliştirme sırasında Visual Studio Code ve Live Server gibi araçlar kullanılabilir.

## Geliştirme Hakkında

NallıhanGo, web geliştirme alanında kendimi geliştirmek ve yerel ihtiyaçlara yönelik bir sipariş arayüzü oluşturmak amacıyla üzerinde çalıştığım bir projedir.

Proje geliştikçe yeni özellikler eklemeyi ve mevcut yapıyı iyileştirmeyi planlıyorum.
